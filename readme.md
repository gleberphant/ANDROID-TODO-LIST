# 📝 To-Do List Simples - Android App

Um aplicativo Android minimalista e intuitivo desenvolvido em **Kotlin** para gerenciamento de tarefas do dia a dia. O projeto tem como foco a simplicidade, permitindo ao usuário registrar, listar, editar e excluir tarefas de forma rápida e sem complicações.

---

## 🚀 Funcionalidades

- **Adicionar Tarefas**: Cadastre novas tarefas informando título e detalhes.
- **Listar Tarefas**: Visualize todas as pendências cadastradas em uma lista organizada.
- **Editar Tarefas**: Atualize informações de tarefas existentes a qualquer momento.
- **Excluir Tarefas**: Remova tarefas concluídas ou indesejadas da lista.

## 📱 Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/gleberphant/pucpr_devmobile_as1.git
   ```
2. Abra o **Android Studio**.
3. Selecione **Open an Existing Project** e a pasta raiz do repositório (`PUCPR-DEVMOBILE-AS1`).
4. Aguarde a sincronização do **Gradle**.
5. Conecte um dispositivo Android ou inicie um Emulador (AVD).
6. Clique no botão **Run ( ▶ )** para compilar e executar o aplicativo.
